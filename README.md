# Prompt Library

自用提示词库。按用途分三组：**学习表达**（prompt-01/02/06）、**评论分析**（prompt-03/04/05 + 配件清单）、**工作流与产出**（prompt-07~16）。

## 每个 prompt 的用途

### 学习表达

| 文件                           | 用途                                                                             |
| ---------------------------- | ------------------------------------------------------------------------------ |
| [prompt-01.md](prompt-01.md) | **用大白话解释概念**。给完全没接触过的人讲清楚一个概念：不用术语、配一个生活比方、不超过 3 句话。                           |
| [prompt-02.md](prompt-02.md) | **费曼学习法老师**。第一性原理 + 费曼法带学材料：拆知识点、每次只教一个、先考再讲，学不懂不进入下一个；自动维护学习笔记文件。             |
| [prompt-06.md](prompt-06.md) | **要点扩写成完整文字**（邮件/文案/回复初稿）。核心护栏「可以加话，不可以加料」：措辞句式 AI 可以补，事实数据不许编；写完必须自报「我补充了什么」。 |

### 评论分析

这一组是流水线上的不同环节：**先整理（04），再选尺子分析（03 或 05）**。

| 文件                           | 用途                                                                                            |
| ---------------------------- | --------------------------------------------------------------------------------------------- |
| [prompt-04.md](prompt-04.md) | **评论整理**（预处理）。把截图/粘贴的原始评论整理成编号列表：保留原话不改写、去掉按钮广告等杂质、看不清就标「⚠️此处无法识别」。输出供 03/05 使用。              |
| [prompt-03.md](prompt-03.md) | **产品体验分析尺**。量「这个东西好不好用」。两段式：Prompt 1 造尺子（归纳分类清单，只跑一次，需人工审定）；Prompt 2 用尺子（按定稿清单分类统计好评/差评，反复跑）。 |
| [prompt-05.md](prompt-05.md) | **购买决策分析尺**。量「该不该买 / 买哪款 / 多少钱 / 什么时候买」。结构同 03，但态度对象是购买决策而非产品本身，立场分 6 档（正向/负向/混合/中性/无关/无法判断）。 |
| [产品层清单-手机版.md](产品层清单-手机版.md) | **prompt-03 的配件，不是提示词**。手机版的 11 类分类清单，用时整段替换 prompt-03 里「产品层·耳机版」那一段，通用层不动。                   |

### 03 还是 05？选尺子

材料主要聊「用起来的感受」→ prompt-03；主要聊「买不买、换不换、怎么买划算」→ prompt-05；两者都有就各跑一遍分开报。详见 prompt-05 开头的对照表。

### 工作流与产出（07–16）

这一组是**做事的方法**，顺序大致是：出图 → 审图 → 排查 → 记录 → 沉淀。

| 文件 | 用途 |
| --- | --- |
| [prompt-07.md](prompt-07.md) | **AI 出图·单张成品**。一次性出整张（含文字）。局限：改一个字就要整张重画，改完背景还可能变。 |
| [prompt-08.md](prompt-08.md) | **AI 出图·无文字底图**。流程化的第一步，底图可反复复用，改文案/字号都不用重新出图。 |
| [prompt-09.md](prompt-09.md) | **审图找茬**。给一张检查清单，要求指名道姓地指出问题；一次只改指出的几处，改完存新版本并编号。 |
| [prompt-10.md](prompt-10.md) | **报错排查**。先自己读一遍报错；一次只走一步；每步报备「改前/改后/影响/风险/撤销」；风险用 🟢🟡🔴 标。 |
| [prompt-11.md](prompt-11.md) | **学习日志撰写**。固定格式 + 明确禁区（不写待办、下一步、问题复盘），且不许替我编内容。 |
| [prompt-12.md](prompt-12.md) | **速查表整理**。按"使用场景"分组而非按语法；只收亲手跑过的，不许补充没用过的。 |
| [prompt-13.md](prompt-13.md) | **文档两版**。本地完整版 + 对外精简版（加「（上传版）」后缀）；**原版一个字都不许改**。 |
| [prompt-14.md](prompt-14.md) | **会话交接启动包**。换会话时把进度打包，必须自包含（新会话看不到之前的对话）。 |
| [prompt-15.md](prompt-15.md) | **事实核实**。路径/版本号/数字/事实先核实再下结论；不确定就说不确定，不许补看似合理的答案。 |
| [prompt-16.md](prompt-16.md) | **存成可复用流程**。标出"固定的"与"每次要改的参数"，并写清"下次遇到什么情况就走这条"。 |
| [prompt-17.md](prompt-17.md) | **企业宣传海报·完整流程**（主流程）。串联 07/08/09：文案 → 素材 → 排版 → 找茬，含素材目录结构、300/72 dpi 出图规格、左对齐等专业排版规则。 |

> 07 与 08 是同一个需求的两种做法，刻意成对保留 —— 对比着看最容易理解"流程化"到底省在哪。

## 共同设计约定

- **造尺子只跑一次，用尺子反复跑**：分类清单定稿后写死，不许边分析边加类。
- **「其他」是报警器，不是垃圾桶**：落不进清单的内容一条不许丢——占比过高说明尺子缺类目，不是材料有问题。
- **防幻觉护栏焊死在模板里**：不许编造搜索结果（02）、不许补全看不清的内容（04）、不许添加没提供的事实（06）。
