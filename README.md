# Prompt Library

自用提示词库。按用途分两组：**学习表达**（prompt-01/02/06）和**评论分析**（prompt-03/04/05 + 配件清单）。

## 每个 prompt 的用途

### 学习表达

| 文件                           | 用途                                                                             |
| ---------------------------- | ------------------------------------------------------------------------------ |
| [prompt-01.md](prompt-01.md) | **用大白话解释概念**。给完全没接触过的人讲清楚一个概念：不用术语、配一个生活比方、不超过 3 句话。                           |
| [prompt-02.md](prompt-02.md) | **费曼学习法老师**。第一性原理 + 费曼法带学材料：拆知识点、每次只教一个、先考再讲，学不懂不进入下一个；自动维护学习笔记文件。             |
| [prompt-06.md](prompt-06.md) | **要点扩写成完整文字**（邮件/文案/回复初稿）。核心护栏「可以加话，不可以加料」：措辞句式 AI 可以补，事实数据不许编；写完必须自报「我补充了什么」。 |

### 评论分析

这一组是流水线上的不同环节：**先整理（04），再选尺子分析（03 或 05）**。

| 文件                           | 用途                                                                                            |
| ---------------------------- | --------------------------------------------------------------------------------------------- |
| [prompt-04.md](prompt-04.md) | **评论整理**（预处理）。把截图/粘贴的原始评论整理成编号列表：保留原话不改写、去掉按钮广告等杂质、看不清就标「⚠️此处无法识别」。输出供 03/05 使用。              |
| [prompt-03.md](prompt-03.md) | **产品体验分析尺**。量「这个东西好不好用」。两段式：Prompt 1 造尺子（归纳分类清单，只跑一次，需人工审定）；Prompt 2 用尺子（按定稿清单分类统计好评/差评，反复跑）。 |
| [prompt-05.md](prompt-05.md) | **购买决策分析尺**。量「该不该买 / 买哪款 / 多少钱 / 什么时候买」。结构同 03，但态度对象是购买决策而非产品本身，立场分 6 档（正向/负向/混合/中性/无关/无法判断）。 |
| [产品层清单-手机版.md](产品层清单-手机版.md) | **prompt-03 的配件，不是提示词**。手机版的 11 类分类清单，用时整段替换 prompt-03 里「产品层·耳机版」那一段，通用层不动。                   |

### 03 还是 05？选尺子

材料主要聊「用起来的感受」→ prompt-03；主要聊「买不买、换不换、怎么买划算」→ prompt-05；两者都有就各跑一遍分开报。详见 prompt-05 开头的对照表。

## 共同设计约定

- **造尺子只跑一次，用尺子反复跑**：分类清单定稿后写死，不许边分析边加类。
- **「其他」是报警器，不是垃圾桶**：落不进清单的内容一条不许丢——占比过高说明尺子缺类目，不是材料有问题。
- **防幻觉护栏焊死在模板里**：不许编造搜索结果（02）、不许补全看不清的内容（04）、不许添加没提供的事实（06）。
